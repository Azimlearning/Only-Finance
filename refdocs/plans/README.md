# Plans

> **MANDATORY:** Before implementing any non-trivial feature, a plan document must exist in this folder.
> A plan covers **what** and **why**. The **how** and **in what order** belongs in `refdocs/execution/`.

## Naming convention

`YYYY-MM-DD-<slug>.md`. **The execution doc uses the identical filename** in `refdocs/execution/`.

## Required sections in every plan

1. Why this exists · 2. What's already covered · 3. Scope (in/out with reasons) · 4. Approach · 5. Risks & unknowns (honest confidence) · 6. Definition of done (observable facts)
